# Automotive AI Assistant: Performance Optimizations

This document outlines the systematic optimizations applied to the application to reduce Time to First Token (TTFT) and overall inference latency, especially for the local AI engine running on Qualcomm SA8255.

## 1. Tool-Augmented RAG (Retrieval-Augmented Generation) Limit Reduction
* **Location:** `ToolManager.kt`
* **Change:** Reduced the top-K returned tools from `30` to `8` in `SemanticSearchManager.search`.
* **Impact:** Prevents the system from injecting 30 full tool definitions into the LLM system prompt. By only providing the 8 most semantically relevant tools, we save approximately ~800-1000 tokens of context window size per interaction, drastically reducing the KV cache generation time during prompt pre-fill.

## 2. LLM System Prompt Compression
* **Location:** `LLMManager.kt`
* **Change:** Stripped highly verbose, hard-coded examples (Example 1 through 10) for standard car controls like HVAC and Sightseeing. 
* **Impact:** The LLM is already capable of executing basic parameter assignments based purely on the tool definitions generated by the RAG system. Stripping these ~400 redundant tokens further optimizes the initial KV cache computation step.

## 3. Asymmetric Telemetry Context Loading
* **Location:** `AssistantSession.kt`
* **Change:** Mirrored an optimization originally written in `LocalLLMActivity.kt`. When a voice query is intercepted, the system evaluates its length. If the query is short (`< 25 characters` like "pause music" or "navigate to work"), it completely bypasses injecting the full hardware telemetry (`[Current State: ...]`) block into the query.
* **Impact:** For short, non-complex queries, this skips evaluating roughly ~200+ tokens of raw hardware data, bringing Voice Overlay TTFT down from ~3.8s to ~1s.

## 4. Input Sanitization for Edge Cases
* **Location:** `LocalLLMActivity.kt`
* **Change:** Fixed the `/diagnostics` trigger bug caused by Android's default keyboard auto-capitalization (turning `/diagnostics` into `/Diagnostics`), which caused the system to process the command as an LLM query rather than an internal UI hook.
* **Impact:** Restores accessibility to the offline hardware verification tool.
